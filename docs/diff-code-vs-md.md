> **Dự án:** Hệ thống web thuyết minh tự động đa ngôn ngữ cho điểm du lịch  
> **Chế độ thực hiện:** CHỈ ĐỌC (Read-Only) – Không tự ý chỉnh sửa code gốc khi chưa có chỉ định, không phán xét đúng/sai.  
> **Nguyên tắc đối chiếu:**  
> - Tài liệu chuẩn nằm tại `Seminar/docs`. Các nội dung bị gạch ngang `~~...~~` là nội dung cũ, **chỉ xem nội dung sau `[ĐÃ SỬA 16/11]` là chuẩn tuyệt đối**.  
> - Bảng dưới đây ghi nhận sự sai khác khách quan giữa code thực tế và tài liệu `.md`.

## 1. TỔNG QUAN HỆ THỐNG & TECH STACK (DISCOVERY)

Sau khi quét toàn bộ các file cấu hình và source code mới nhất (`package.json`, `web/package.json`, `.env.example`, `docker-compose.yml`, `schema.sql`, `migrations/`), hệ thống được xác định với các thông số kỹ thuật sau:

- **Ngôn ngữ:** TypeScript (chạy trên Node.js v22+ ở Backend và trình duyệt hiện đại ở Frontend).
- **Backend Framework:** NestJS v11 (kiến trúc Modular Monolith gồm các module: `AuthModule`, `CatalogModule`, `ContentModule`, `VisitorModule`, `DatabaseModule`, `HealthModule`).
- **Frontend Framework:** React 19 kết hợp Vite v8, CSS thuần (`styles.css`), kiến trúc SPA phân nhánh đường dẫn (`/admin` cho Content Studio và `/` hoặc `/visitor` cho khách tham quan). Đã tích hợp thư viện `qrcode.react` để vẽ và tải xuống ảnh mã QR trực tiếp trên trình duyệt.
- **Cơ sở dữ liệu:** PostgreSQL 17 (Alpine qua Docker Compose).
- **Truy cập dữ liệu (Data Access / ORM):** Sử dụng thư viện `pg` (node-postgres Pool) với các câu lệnh SQL thuần được đóng gói trong Repository Pattern (không dùng ORM như TypeORM, Prisma hay Drizzle).
- **Xác thực & Phân quyền:** JWT (`@nestjs/jwt`), mã hóa mật khẩu bằng `bcrypt`, bảo vệ route bằng Custom Guard (`JwtAuthGuard`, `RolesGuard`) và decorator `@Roles()`. Hai vai trò chính: `ADMIN` và `CONTENT_MANAGER`.
- **Dịch vụ tích hợp bên ngoài:**
  - Google Cloud Translation API (dịch tự động đa ngôn ngữ).
  - ElevenLabs Text-to-Speech API (chuyển văn bản thành audio giọng đọc).
- **Lưu trữ tệp đa phương tiện:** Lưu trên ổ đĩa cục bộ (thư mục `storage/` với hai nhánh `tts/` và `uploads/`), phục vụ file tĩnh qua route `/media/`.
- **Tiếp cận điểm tham quan & Thống kê trực tuyến:**
  - Hoàn toàn dựa trên duyệt Web và quét mã QR Code dẫn link POI (không sử dụng định vị vệ tinh GPS).
  - Đã bổ sung cơ chế Heartbeat (`POST /visitor/presence`, bảng `visitor_presence`) gửi mỗi 15 giây từ phía visitor để theo dõi số lượng khách trực tuyến trong 10 phút gần nhất.
